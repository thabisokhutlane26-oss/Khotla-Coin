# Khotla Coin (KHT)

Khotla Coin is a cryptocurrency project created by Thabiso Khutlane.

## Project

- Name: Khotla Coin
- Symbol: KHT
- Blockchain: Khotla Chain
- Network: Khotla Testnet
- Mobile Wallet: Khotla Wallet

## Version 1

The first version will include:

- Wallet creation
- KHT balance
- Send KHT
- Receive KHT
- Transaction history
- Wallet address
- PIN protection
- Testnet transactions

## Development

Khotla Coin is currently being developed as a testnet project.

Real-money deposits, withdrawals and trading will only be added later after the necessary technical, security and regulatory requirements are addressed.
